## About
A software Traffic Light Controller (TLC) for a standard 4-way intersection.
Supports pedestrian crossing requests, traffic detection, and EMS priority
requests. See `/docs` for the full Requirements Definition Document (RDD)
and future design docs.

## Repo structure
- `/docs` — RDD, SRS, design diagrams, meeting notes
- `/src` — Java source (Maven project)
